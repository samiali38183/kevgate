**Goal:** a FastAPI service that accepts scan findings and returns them ranked for remediation.
**You write all code in `src/kevgate/`.** The tests in `tests/` are the contract; don't edit them to make them pass. Time box: 5 sessions of 90 min. Hints on request: `stuck on M1 <part>, want L1/L2/L3`.

## Contract

### `kevgate/scoring.py`
`risk_score(cvss: float, epss: float, acr: int, in_kev: bool) -> float`
- Weights: KEV 0.40, ACR 0.25 (acr/8), EPSS 0.20, CVSS 0.20 (cvss/10). Divide by the weight total, multiply by 100, round to 1 decimal.
- Must stay in 0..100. Any KEV finding on an asset must outrank a non-KEV finding with the same acr.

`load_kev(path: str) -> frozenset[str]`
- Reads the CISA feed schema (`{"vulnerabilities": [{"cveID": ...}]}`), returns upper-case CVE IDs.

### `kevgate/app.py`
`create_app(kev_path: str) -> FastAPI`. Keep state inside the app (no module-level globals), so each test gets a fresh store.

| Endpoint | Behavior |
|---|---|
| `GET /healthz` | 200 `{"status": "ok"}` |
| `POST /findings` | body: JSON list of findings. 201 `{"accepted": n}`. 422 if any item is invalid (nothing stored). |
| `GET /queue?limit=10` | 200, list sorted by `risk` descending, ties by `epss` then `cvss`. `limit` 1..100, default 10; out of range -> 422. |

Finding fields: `cve` (pattern `CVE-\d{4}-\d{4,}`, case-insensitive, stored upper-case), `asset` (1-128 chars), `acr` (int 1..8), `cvss` (0..10), `epss` (0..1), `days_open` (int >= 0).
Queue items: every finding field plus `kev` (bool) and `risk` (float).
